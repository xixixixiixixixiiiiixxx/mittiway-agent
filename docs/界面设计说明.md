# 界面设计说明

界面围绕客服的实际任务组织为四个入口：客服对话、设备知识库、会话与本地工单、开发与实施。桌面右栏解释知识来源与本轮处理，移动端将主要导航放在底部，保留提问入口。

本次使用 ui-ux-pro-max 的设计系统搜索，匹配到简洁企业风格与海军蓝配蓝色强调色；专门的客服工作台产品类别搜索没有取得有效匹配，因此按任务和通用可访问性规则自行确定工作台布局，没有套用搜索结果中的营销首页结构。

实现使用原生 HTML、CSS 和 JavaScript，避免为一个演示引入构建依赖。图标为本地 SVG，关键内容和答复保留可读字号、键盘焦点、可见输入反馈和减少动态效果支持。知识统计来自实际记录，没有伪造业务转化、响应率或人工在线状态。

原始 PDF、官网资料、开发流程和本地工单各自标注用途。界面不把检索分数显示成“答案可信度”，也不把模拟工单显示成已送达厂家。
